# PFinance: назначение продукта

## Проблема

Семейный учёт финансов часто ведётся в перегруженных таблицах, которые неудобно заполнять с телефона. В результате данные быстро перестают быть актуальными.

## Назначение

PFinance должен стать простым mobile-first инструментом, который помогает семье:

- быстро фиксировать движение денег;
- понимать текущее состояние финансов;
- контролировать лимиты без сложной аналитики;
- видеть понятный cash flow.

## Принципы

1. Телефон — основной сценарий.
2. Минимум ручного ввода.
3. Финансовые показатели должны быть понятны без инструкции.
4. Каждая новая функция должна оправдывать свою сложность.

## Границы текущего этапа

В подготовительном релизе нет операций, счетов, бюджетов, базы данных, авторизации и полноценного интерфейса. Этот этап фиксирует только техническую основу.
