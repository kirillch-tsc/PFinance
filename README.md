# PFinance

Мобильное веб-приложение для простого семейного учёта денег.

## Возможности

- общий баланс и балансы наличных/кредитной карты;
- доходы, расходы и переводы;
- cash flow за месяц;
- бюджеты по категориям;
- быстрое добавление операций с телефона;
- локальное сохранение данных в браузере.

## Запуск

```bash
npm install
npm run dev
```

Сборка и проверка:

```bash
npm test
```
